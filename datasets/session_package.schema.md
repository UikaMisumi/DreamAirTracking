# DreamAirTracking Capture Package Schema

Capture packages are local zip files generated by the app and shared manually by the user. The app should not upload them.

```text
DreamAirTrackingCapture_YYYYMMDD_HHMMSS/
  session.json
  device.json
  capture_protocol.json
  labels.jsonl
  pairs.csv
  metrics.json
  calibration_report.md
  frames/
    center_000001_left.jpg
    center_000001_right.jpg
  optional_runtime/
    live_multitask_*.csv
```

## device.json

```json
{
  "schema": "dream_air_tracking.device.v1",
  "deviceFamily": "Dream Air",
  "subjectId": "anonymous-local-id",
  "wearId": "wear_001",
  "brokenEyeVersion": null,
  "vrcftVersion": null,
  "runtimeModelId": "optional-model-id",
  "notes": ""
}
```

## capture_protocol.json

```json
{
  "schema": "dream_air_tracking.capture_protocol.v1",
  "protocolId": "nine_point_gaze",
  "stages": ["center", "up", "down", "left", "right", "left_up", "right_up", "left_down", "right_down"],
  "intendedTrainingHeads": ["gaze_xy"],
  "headMasksRequired": true
}
```

## Training Rules

- Gaze stages supervise only `gaze_xy`.
- Eyelid stages supervise only `openness_lr` unless explicitly labeled otherwise.
- Wide/squint stages supervise only `wide_lr` / `squint_lr`.
- Pupil weak labels require quality and openness gates.
- No row should silently supervise every head.
